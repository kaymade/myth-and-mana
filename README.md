# Myth & Mana

**Myth & Mana** is a fantasy RPG-inspired editorial magazine website built with HTML and CSS. The project is designed as a fictional digital magazine issue featuring quests, field notes, relics, spellbook entries, and a full feature article.

The goal of this project was to practice responsive layout, CSS Grid, typography, visual hierarchy, clickable article cards, and creative theme development while keeping the final design polished and portfolio-friendly.
